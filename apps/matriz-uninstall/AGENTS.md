# AGENTS.md — Matriz Uninstall

Privileged Windows behavior belongs only to a desktop adapter. The renderer may
send product and installation IDs, never commands, executable paths or cleanup
paths. Both shells implement the same `DesktopGateway` and contract tests.

Read `../../docs/release-distribution.md` before changing downloads, versions or packaging. IDs: `matriz-uninstall-tauri` (`uninstall-v*`) and `matriz-uninstall-electron` (`uninstall-electron-v*`). Local folder paths remain native-only.
