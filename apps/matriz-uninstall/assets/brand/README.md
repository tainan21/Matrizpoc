# Matriz Uninstall identity

Matriz Uninstall is an extension of Matriz Control. Violet identifies the Matriz family; mineral green is reserved for verified, recoverable and safe outcomes.

- Primary: `#9c5ee3`
- Verified: `#45d59a`
- Canvas: `#0b0710`
- Foreground: `#f4eff9`

The mark is an `M` joined to an open reversible cycle. Do not rotate it, close the cycle, recolor verified states red, or replace it with a trash/recycling symbol. Use `symbol.svg` for square surfaces and `lockup.svg` when the product name must be explicit.
