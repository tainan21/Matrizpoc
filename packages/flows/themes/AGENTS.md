# Themes flow boundaries

- Responsibility: pure preference resolution, compatibility and safe fallback for CSS-first themes.
- Allowed imports: foundation constants and pure design contracts.
- Forbidden imports: `apps/*`, React, Next.js, Prisma, HTTP clients and persistence adapters.
- Accepted: deterministic policy, versioned theme references and accessibility preference shapes.
- Rejected: CSS payload persistence, marketplace payment logic and app-specific presentation.
