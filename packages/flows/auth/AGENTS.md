# Authentication flow boundaries

- Responsibility: compose the shared mock passwordless login experience.
- Allowed imports: `design/*`, `platform-auth`, foundation types/constants.
- Forbidden imports: every `apps/*` path and all strong product-domain code.
- Accepted: generic login states, method selectors, accessibility behavior.
- Rejected: Spot gigs, Seumei establishments, Contracts documents or WillDash goals.
