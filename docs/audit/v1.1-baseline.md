## V1.1 gaps closed in this iteration

1. **Auth**: package went from mock-types to real V1.1 core (provider,
   hooks, guards, strategies, storage adapter, context, services, mappers).
2. **Login**: all 5 apps got `/login` with their own UI, using 2 strategies
   (magic link: hub + contracts + willdash; OTP: spot + seumei).
3. **Semantic layout**: `src/auth/` and `src/domains/<d>/presentation/`
   added across the 5 apps.
4. **Deploy**: `vercel.json` × 5, `build-deploy-model.md`,
   `vercel-deployment-map.md`, deploy workflow with per-app matrix.
5. **Split**: `export-app.ts`, `split-apps.yml`, `app-extraction-model.md`.
6. **Boundaries**: added `verify-app-boundaries.ts` + two new smoke tests.
7. **Readiness**: `check-readiness.ts` produces a single-number score.

## Known intentional gaps (not bugs)

- `matriz-hub` has no `domain/application/integration` trees by design:
  the Hub consolidates events and external-links from the other four.
- `contracts` and `willdash` have `src/integration/adapters/` but no
  `gateways/` — they emit DTOs but do not actively call other apps.
- Session storage uses `localStorage`. Swap to HTTP-only cookies is a
  pure adapter change when moving to real backend (see ADR 0001).
