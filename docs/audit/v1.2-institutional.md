## Riscos residuais

| Risco | Severidade | Mitigação atual |
|---|---|---|
| `ProjectManifest` e `AppManifestDTO` podem ser confundidos | Baixa | Docs dedicados (`project-intelligence-contracts.md`) explicam papéis distintos |
| Drift entre categorias de telemetria em `platform-telemetry` e `integration/api-contracts` | Baixa | Lista pequena (6 strings); smoke cobre cada categoria |
| Decoration institucional hardcoded no Hub não escala | Média | Endereçado em `cross-repo-integration-model.md`: evolução natural é mover a decoração para o próprio repo via snapshot |
| Scaffolds de adapter podem ser chamados por engano | Baixa | Lançam `NotImplementedError` explícito; typecheck impede uso sem `fetchManifest`/`handle`/etc. |
| Fonte externa simulada é JSON estático no Hub | Esperada | É o propósito do scaffold — prova conceito sem rede |
| Telemetria não persiste entre reinícios | Esperada | In-memory por design; persistência real é fase seguinte |
